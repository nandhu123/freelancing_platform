# 🚀 Freelancing Platform

A Django-based freelancing platform where freelancers and recruiters can connect, chat, and manage projects.

---

## ✨ Features
- User Registration & Login  
- Freelancer Dashboard  
- Recruiter Dashboard  
- Job Posting & Applications  
- Interview Scheduling  
- Messaging System  
- Notifications  
- Settings Page  

---

## 🛠️ Tech Stack
- Python  
- Django  
- Django REST Framework  
- HTML, CSS, JavaScript  
- SQLite  

---

## ⚙️ Run Project

### Install requirements
```bash
pip install -r requirements.txt
```

### Apply migrations
```bash
python manage.py makemigrations
python manage.py migrate
```

### Run server
```bash
python manage.py runserver
```

### Open in browser
http://127.0.0.1:8000/
